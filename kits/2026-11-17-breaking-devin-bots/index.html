Cognition

Setup steps, in order

  1. Go to devin.ai/bots, where Bots are available.
  2. Have an administrator set which code repositories and tools the Bot can access.
  3. Send the Bot a goal message in Slack, iMessage or the Devin app.

Questions to ask before you start

  • Which repositories and tools can the Bot access?
  • Which changes need human review before they merge?
  • What budget and cost apply to our plan?

Prompts to try on day one

  • Keep our Android app at parity with iOS and ask me before any change to the release branch.
  • Watch our Linear backlog and send me the decisions you need from me in one Slack thread.
  • Manage our next release and post any open questions in this thread.
