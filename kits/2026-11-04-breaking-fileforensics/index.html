The fileForensics starter kit

fileAI

Setup steps, in order

  1. Go to developer.file.ai and sign up for an account.
  2. Upload a file and read the scorecard in your browser.
  3. Or connect it to Claude, Codex or Cursor through the MCP server.

Questions to ask before you start

  • Who on your team reviews a file the tool flags?
  • What are the file type, size and data retention terms?
  • What does a run cost on the pricing page today?

Prompts to try on day one

  • Check this PDF with fileForensics and list the findings with the evidence.
  • Run fileForensics on this image and tell me whether a person should look first.
  • Check this file against ones we have seen and flag any exact duplicates.
