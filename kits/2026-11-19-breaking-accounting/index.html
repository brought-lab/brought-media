OpenAI

Setup steps, in order

  1. Open the ChatGPT desktop app, search the plugin directory for Accounting, and select Install plugin.
  2. Follow the computer use setup instructions.
  3. Upload an Excel template and the files you need, or connect an accounting app.

Questions to ask before you start

  • Has an admin approved the plugin if we are on Enterprise?
  • Which files and accounting apps am I allowed to connect?
  • Who reviews the drafts before anything is approved?

Prompts to try on day one

  • Tie out this bank statement to the general ledger and list unmatched transactions by date and amount.
  • Review this month end workbook for broken formulas, inconsistent totals and possible duplicate entries.
  • Flag any missing information or uncertain coding in these invoices before I review them.
